# OpenCV Object Detector

Приложение на Python и OpenCV для обнаружения объектов на изображении или
кадре с камеры. Детектор строит повёрнутые рамки, показывает направление и
координаты центра, группирует похожие формы по ID и определяет наличие надписи
внутри прямоугольной плашки.

## Возможности

- обработка изображения в разрешении 640×480;
- загрузка изображения из файла или получение кадра с камеры;
- настройка разрешения, FPS, экспозиции, фокуса и других параметров камеры;
- поиск внешних контуров и фильтрация мелкого шума;
- повёрнутая рамка, оси направления и координаты центра объекта;
- красные текстовые подписи на кадре;
- одинаковый ID для объектов с похожей формой;
- различение острых и скруглённых прямоугольных объектов;
- определение `signed` и `blank` по содержимому внутри плашки;
- распознавание русского текста и строгая группировка одинаковых надписей;
- автоматические и вручную назначаемые категории;
- визуальная отладка всех этапов обработки;
- графический интерфейс для изменения параметров без перезапуска программы.

## Файлы проекта

- `detector_ui.py` — основной графический интерфейс;
- `detect_objects.py` — запуск детектора из командной строки;
- `object_detector.py` — обработка изображения и классификация объектов;
- `visual_debug.py` — отдельное окно визуальной отладки;
- `categories.json` — названия пользовательских категорий;
- `detector_config.json` — сохранённые параметры детектора по умолчанию;
- `requirements.txt` — зависимости проекта;
- `requirements-rpi.txt` — дополнительные Python-зависимости для Raspberry Pi OS;
- `images/` — входные изображения и снимки с камеры.

## Установка

В PowerShell перейдите в папку проекта, создайте виртуальное окружение и
установите зависимости:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Для OCR дополнительно требуется системная программа Tesseract с русской
языковой моделью. В Windows установите Tesseract OCR, добавьте его в `PATH`
или используйте стандартный путь `C:\Program Files\Tesseract-OCR`. В
Debian/Ubuntu и Raspberry Pi OS:

```bash
sudo apt update
sudo apt install tesseract-ocr tesseract-ocr-rus
```

Если окружение `venv` находится на один уровень выше папки проекта:

```powershell
..\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Графический интерфейс

Обычный запуск:

```powershell
python detector_ui.py
```

Открыть конкретное изображение:

```powershell
python detector_ui.py --image images/123.jpg
```

Сразу открыть камеру с индексом `0`:

```powershell
python detector_ui.py --camera 0
```

Горячие клавиши:

- `Ctrl+O` — открыть изображение;
- `Ctrl+K` — открыть камеру;
- `Ctrl+S` — сохранить результат;
- `F5` — повторить обработку.

Все параметры UI при запуске загружаются из `detector_config.json`. Кнопка
«Сохранить как параметры по умолчанию» записывает в этот файл текущие значения,
а кнопка «По умолчанию» повторно загружает сохранённые параметры. Эти же
значения используются при запуске `detect_objects.py` и `visual_debug.py`, если
соответствующий параметр не указан в командной строке.

После снимка с камеры фотография сохраняется в папке `images` и автоматически
выбирается для обработки. Такие снимки имеют имя `camera_*.jpg` и не добавляются
в Git.
Кнопка «Серия 3 снимка / 10 секунд» сохраняет кадры в моменты 0, 5 и 10 секунд.
Объекты между кадрами сопоставляются по координатам центра. OCR-текст принимается
только при совпадении минимум в двух кадрах; источник результата отображается
как `series(2/3)` или `series(3/3)`.

## Категории

По умолчанию используются две автоматические категории:

1. Острые и скруглённые прямоугольные объекты.
2. Другие объекты.

В UI можно открыть редактор категорий, добавить новую категорию, переименовать
существующую или удалить пользовательскую. Для ручного назначения выберите
объект в таблице, категорию и нажмите «Выбранным» либо «Всему ID».
Значение «Автоматически» отменяет ручное назначение. Названия сохраняются в
`categories.json`; назначения объектов действуют в текущем сеансе программы.

## Группы текста

OCR запускается для всех найденных прямоугольных плашек. Текст проверяется в
четырёх ориентациях, приводится к верхнему регистру, очищается от пробелов и
получает `Text ID`. В Tesseract передаётся отдельный бинарный OCR-слой:
выровненная внутренняя область исходного изображения с нормализованным фоном и
порогом Otsu. Canny и морфология используются только для поиска объектов.
Одинаковый текст в одном кадре получает одинаковый `Text ID`:

```text
ДАТЧИК-1 → Text ID 1
ДАТЧ     → Text ID 2
ДАТЧИК-1 → Text ID 1
```

Группировка строгая: недописанная строка не объединяется с полной. Результат с
низкой уверенностью получает статус `low_confidence` и не включается в группу.
Перед запуском Tesseract OCR-слой проверяется на фрагментированность. Если число
значимых разрозненных компонентов превышает `ocr_max_components`, шум не
передаётся распознавателю и получает статус `noise_rejected`. Предел доступен в
UI как «Макс. фрагментов OCR»; значение по умолчанию — `12`.
Для сомнительного результата программа дополнительно сравнивает режимы
сегментации PSM 7, 11 и 12. Совпавший текст принимается по голосованию; проверку
можно отключить, а минимальное число совпадений изменить в UI. Это позволяет
подтвердить стабильный результат при заниженной оценке Tesseract, не принимая
случайный шум на пустой плашке.
Назначенные `Text ID` сохраняются между последовательно обработанными снимками
в течение текущего сеанса UI.
Значения `unavailable` и `language_missing` означают, что не найден Tesseract
или русская языковая модель. В UI доступны включение OCR, язык, режим
сегментации, минимальная уверенность, масштабирование области текста и
консольная OCR-отладка. Она выводит сырой и нормализованный текст, уверенность,
статус и назначенный `Text ID` для каждого объекта.

Режим просмотра «OCR-слой» показывает именно бинарное изображение, которое
передаётся Tesseract, вместе с выбранным поворотом, уверенностью и статусом.
Для каждого объекта рядом отображаются состояния `BEFORE` и `AFTER`, то есть
слой до поворота и фактический результат выбранного `rot`.
На изображении `AFTER` распознанные Tesseract слова выделяются рамками:
зелёной для подтверждённого результата и оранжевой для низкой уверенности.
Строка `Scores` показывает итоговые баллы поворотов `0`, `90`, `-90` и `180`.
В оценку входят уверенность Tesseract, геометрия строки, непрерывный baseline и
соответствие ожидаемому формату. В поле «Ожидаемый формат (regex)» можно задать,
например, `^Д\d{2}$`. Несовпавший текст получает статус `format_mismatch` и не
включается в группу; программа не исправляет и не дописывает его автоматически.
Если ни один вариант не достиг минимальной уверенности, используется параметр
`ocr_fallback_rotation` из `detector_config.json` (по умолчанию `-90`). Это не
позволяет случайному низкоуверенному символу перевернуть строку вверх ногами.
Если на плашке присутствует длинная подчёркивающая линия, ориентация получает
дополнительный геометрический балл: линия должна быть непрерывной и находиться
под текстом. Разрозненные точки больше не складываются в ложный baseline.
Минимальная относительная длина линии задаётся параметром
`ocr_baseline_min_ratio`.
Этот же слой добавлен отдельным рядом в общую панель «Отладка».
Распознанная строка отображается красным цветом непосредственно на итоговом
кадре и над соответствующим фрагментом в OCR-отладке.

## Запуск из командной строки

```powershell
python detect_objects.py --image images/123.jpg
```

На Raspberry Pi OS Lite или при запуске по SSH добавьте `--no-display`:

```bash
python detect_objects.py --image images/123.jpg --no-display
```

Получить один кадр с USB-камеры `/dev/video0`, сохранить разметку и JSON:

```bash
python detect_objects.py --camera 0 --no-display \
  --output result.jpg --json-output result.json
```

Для передачи JSON другой программе через стандартный вывод используйте `-`.
Человекочитаемые сообщения в этом режиме направляются в `stderr`, поэтому
`stdout` содержит только корректный JSON:

```bash
python detect_objects.py --camera 0 --no-display --json-output -
```

Сохранить размеченное изображение:

```powershell
python detect_objects.py --image images/123.jpg --output result.png
```

Открыть визуальную отладку:

```powershell
python detect_objects.py --image images/123.jpg --debug
```

Сохранить панель отладки:

```powershell
python visual_debug.py --image images/123.jpg --output debug.png
```

Основные параметры CLI:

```text
--image PATH                    путь к изображению
--camera INDEX                  индекс USB/V4L2-камеры
--camera-warmup-frames COUNT    число пропускаемых прогревочных кадров
--output PATH                   путь сохранения результата
--json-output PATH|-            сохранить JSON в файл или вывести в stdout
--no-display                    не открывать графическое окно
--min-area NUMBER               минимальная площадь контура
--similarity-threshold NUMBER   порог сходства форм для одинакового ID
--signed-threshold NUMBER       порог определения надписи
--no-ocr                        отключить OCR
--ocr-language CODE             язык Tesseract, по умолчанию rus
--ocr-min-confidence NUMBER     минимальная уверенность OCR от 0 до 100
--debug                         показать панель визуальной отладки
--debug-output PATH             сохранить панель визуальной отладки
```

Чем меньше `--similarity-threshold`, тем строже сравниваются формы. Чем меньше
`--signed-threshold`, тем чувствительнее поиск надписи внутри плашки.

## Raspberry Pi 5 без рабочего стола

Для Raspberry Pi OS Lite рекомендуется 64-битная система, USB-камера с
интерфейсом V4L2 и отдельное виртуальное окружение Python. Установите системные
пакеты:

```bash
sudo apt update
sudo apt install -y python3-full python3-venv python3-opencv python3-numpy \
  python3-scipy python3-pil tesseract-ocr tesseract-ocr-rus v4l-utils
sudo usermod -a -G video "$USER"
```

После добавления в группу `video` выйдите из сеанса и войдите снова. Проверьте
камеру и OCR:

```bash
v4l2-ctl --list-devices
tesseract --list-langs
```

Создайте окружение с доступом к пакетам, установленным через `apt`, и поставьте
оставшиеся зависимости:

```bash
python3 -m venv --system-site-packages venv
source venv/bin/activate
python -m pip install -r requirements-rpi.txt
```

Программа автоматически не открывает окно, если переменные `DISPLAY` и
`WAYLAND_DISPLAY` отсутствуют. Для предсказуемого запуска в службе или по SSH
всё равно рекомендуется явно указывать `--no-display`.

## Координаты и подписи

Начало координат `(0, 0)` находится в левом верхнем углу. Ось X направлена
вправо, ось Y — вниз. Жёлтая точка обозначает центр объекта, зелёная линия —
рамку, фиолетовые линии — его направление. Красная подпись содержит категорию,
ID, состояние `signed/blank` и координаты центра.
